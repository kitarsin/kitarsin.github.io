02 ⌘InsomniCode · ThesisODIN Core API The analysis engine behind ODIN’s adaptive tutoring.

My contribution · Primary backend developer

The API is part of InsomniCode’s ODIN thesis project. I developed most of the backend, which powers code submission analysis and adaptive tutoring.

What it does

This ASP.NET Core API processes student code submissions through a pipeline that combines behavioral signals, structural code analysis, knowledge scoring, and affective-state checks before selecting a teaching intervention.

  • Roslyn code analysis
