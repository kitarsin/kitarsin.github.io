01 ◈InsomniCode · ThesisODIN A web-based C# arrays tutor with a React student portal, embedded Godot game, and connected API.

InsomniCode · Thesis project

ODIN is a web-based, gamified intelligent tutoring system for college-level C# arrays. Its React and TypeScript student portal embeds a Godot game and connects to the Core API for code submissions, progress tracking, and contextual feedback. Current tasks focus on array problem-solving, especially off-by-one and out-of-bounds errors.

Website · Primary developer

I built most of the learner-facing React and TypeScript web client, which includes student and instructor experiences, Supabase authentication and profile data, and the embedded Godot Web game. I host the website on Vercel.

Core API · Primary backend developer

I developed most of the ASP.NET Core backend, maintain its Supabase PostgreSQL database, and handle backend hosting on Railway.

The API authenticates requests with Supabase JWTs and processes submissions through behavior classification, Roslyn-based C# array diagnostics, mastery tracking, affective-score recording for research and administration, and intervention selection. It returns contextual feedback, hints, NPC dialogue, rewards, and progress updates. Its behavior and affective signals support instruction and research; they are not clinical diagnoses.

  • C# array diagnostics
  • Behavior and submission telemetry
  • Mastery tracking
  • Contextual hints and NPC dialogue

02 文Personal projectLinguaLoom A browser extension for literary translation on Wattpad.

My role · Creator and developer

LinguaLoom is my independent project. I’m building and refining the extension to translate fiction chapters directly in the browser.

What it does

LinguaLoom is a WebExtension for translating fiction chapters. It can run with a local mock provider or use your own OpenRouter key, keeping provider requests in the extension background and requiring no LinguaLoom backend.

  • Firefox and Chromium
  • Bring your own key
  • Restore the original chapter
